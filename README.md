## About

This project contains my Week 4 internship task on planning a Security Awareness Campaign for a hypothetical organization.

The objective of this task is to educate employees about cybersecurity best practices, common cyber threats, safe digital behavior, and incident reporting.

## Topics Covered

* Cybersecurity Awareness
* Phishing Awareness
* Password Security
* Multi-Factor Authentication
* Social Engineering
* Malware Awareness
* Data Protection
* Safe Internet Usage
* Device Security
* Remote Work Security
* Incident Reporting
* Employee Engagement
* Security Awareness Activities
* Campaign Measurement
* Continuous Security Awareness

## Campaign

The campaign is based on the theme:

**“Think Before You Click – Pause. Verify. Protect.”**

The plan includes a four-week awareness schedule using emails, posters, training sessions, quizzes, phishing simulations, security tips, and interactive activities.
